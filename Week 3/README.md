## Cara Menjalankan

**Kebutuhan Sistem:**
- Sistem operasi Windows
- .NET 8.0 SDK atau versi lebih baru
- .NET 8.0 Desktop Runtime

**Langkah-langkah:**

1. Buka terminal dan masuk ke direktori project.
```
cd Kalkulator
```

2. Pulihkan dependensi project.
```
dotnet restore
```

3. Build dan jalankan aplikasi.
```
dotnet run
```

Jendela kalkulator akan muncul secara otomatis dan siap digunakan.
